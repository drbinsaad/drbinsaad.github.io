# 03 — Daily Workflows

The whole system is one habit: **the 3-minute capture loop**. Everything else supports it.

## The 3-minute capture loop (do this every time you learn something)

1. **Consume** — watch the video, attend the lecture, read the paper, sit in the conference talk.
2. **Open the topic note** — `Ctrl/Cmd+O`, type the topic name (e.g. "Otosclerosis").
3. **Dump takeaways** in your own words under the right heading (Management, Pearls, etc.).
4. **Paste the source link** under *Sources* (for a key paper, make a full note in `09 Sources`
   instead and link it in).
5. **Bump `status`** — `untouched → learning → solid → mastered`.

Under three minutes. The Dashboard updates itself. If capture ever takes longer than this,
you're over-processing — just dump and move on.

## When to make a full source note (the exception)
Only for a source you'll cite repeatedly (landmark paper, guideline, a whole course). Use the
**Source note** template in `09 Sources`, record the citation, list *Feeds into* topics, then
update those topic notes. Everyday YouTube lectures don't get their own note — a pasted link
in the topic is enough.

## Quick capture (when you're busy)
No time for the loop? Drop one line in `00 Inbox` ("watch Cummings ch. on paragangliomas").
Process it in the weekly review.

## Weekly review (20–30 min, e.g. Friday)
1. **Empty `00 Inbox`** — each item → topic note content, a source note, or deleted.
2. **Open the Dashboard → "Needs work"** — pick your next study targets.
3. **Promote one note** — take something from `learning` to `solid`: add detail, links, a source.
4. **Skim recent notes** — anything half-captured to finish while it's fresh.

## Scenario walkthroughs

### You watch a lecture series on paediatric airway
Open `Clinical Evaluation of Airway Obstruction`, note the stridor/aspiration/cough pearls,
paste the playlist link, set `status: learning`. Tick the subtopics you covered.

### You read a landmark guideline
New **Source note** in `09 Sources`: `Rosenfeld2016 — AAO OME guideline`. Under *Feeds into*,
link `[[Otitis Media]]`. Open that note, add what changed your practice, cite the source note,
bump status.

### You prepare a teaching session
New **Lecture** note in the section folder or a `Teaching` area. Build the outline as links to
existing topic notes — you'll find most content already written. Gaps in the outline = topic
notes to fill first (which serve you forever).

### You're revising for exams / boards
Open the Dashboard, filter to a section's MOC as a syllabus chapter, and study everything not
yet `mastered`. Tick subtopic checklists as you go.

## Anti-rules
- Don't reorganise folders — the curriculum already did that.
- Don't copy-paste textbook chapters. Write *your understanding*, or link the source.
- Don't make a source note for every video — paste the link and move on.
- Don't let the Inbox pass a week unemptied.
- Never record patient identifiers.
