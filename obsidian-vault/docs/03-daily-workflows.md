# 03 — How to use it

One habit. Everything else supports it.

## The 3-minute capture loop
1. **Consume** — watch the video, attend the lecture, read the paper.
2. **Open the topic note** — `Ctrl/Cmd+O`, type the topic (e.g. "Otosclerosis").
3. **Write** what you learned under **Notes**, in your own words. Tick any subtopics you covered.
4. **Paste the source link** under **Sources**.
5. **Bump `status`** — `untouched → learning → solid → mastered`.

Under three minutes. If it takes longer, you're over-processing — just dump and move on.

## Full source notes (the exception)
Only for a source you'll cite repeatedly (landmark paper, guideline, whole course). Make one in
`09 Sources` from the **Source note** template, then link it into the topics it informs.
Everyday videos don't get their own note — a pasted link is enough.

## Quick capture
Busy? One line in `00 Inbox` ("watch Cummings ch. on paragangliomas"). Process it weekly.

## Weekly review (20 min)
1. Empty `00 Inbox`.
2. Open the **Needs work** view → pick your next study targets.
3. Promote one note from `learning` to `solid`.

## Anti-rules
- Don't reorganise folders — the curriculum already did that.
- Don't copy-paste textbooks. Write your understanding, or link the source.
- Don't make a source note for every video.
- Don't let the Inbox pass a week.
- Never record patient identifiers.
