# 📚 Sources

Most of the time you just paste a link into a topic note's **Sources** section — that's enough.

Create a **full source note here** only when a source deserves its own citation and
lives on beyond a single topic: a key journal paper, a landmark guideline, a course you'll
reference repeatedly. Use the **Source note** template, then link it into every topic note
it informs (`[[Otitis Media]]`, `[[Cholesteatoma]]`, …).

Naming: `AuthorYEAR — Short title`, e.g. `Rosenfeld2016 — AAO OME guideline`.
