# ⚙️ Plugins & setup

This vault ships **pre-configured** (see the `.obsidian/` folder): the right core plugins,
sensible settings, a purple accent, `Home` bookmarked, and new notes routed to `00 Inbox`.
On first open you only need to confirm a few things and install the community plugins below.

## Already on (core plugins)
**Bases** (the dashboards), **Templates** (folder set to `_Templates`), Quick switcher,
Backlinks, Outgoing links, Properties, Tag pane, Command palette, Bookmarks, File recovery,
Graph, Outline, Canvas, Slides. If a board is blank, re-enable **Bases** in
Settings → Core plugins.

## Community plugins — install these (Settings → Community plugins → Browse)
Ranked. Install the must-haves first; add the rest when you feel the need.

### Must-have
| Plugin | ID | Why |
|---|---|---|
| **Spaced Repetition** | `obsidian-spaced-repetition` | In-vault flashcards/cloze — see [[Flashcards & revision]] |
| **Templater** | `templater-obsidian` | Powerful templates: auto-date, auto-file new notes by folder |
| **QuickAdd** | `quickadd` | One-hotkey capture: new concept / source / case / flashcard |
| **Excalidraw** | `obsidian-excalidraw-plugin` | Hand-drawn anatomy & surgical diagrams inside notes |
| **Dataview** | `dataview` | Inline queries & task rollups Bases can't do (still useful alongside Bases) |

### Nice-to-have
| Plugin | ID | Why |
|---|---|---|
| **Zotero Integration** | `obsidian-zotero-desktop-connector` | Import citations + PDF annotations (needs Zotero + Better BibTeX) |
| **Style Settings** | `obsidian-style-settings` | GUI toggles for fonts/colours |
| **Iconize** | `obsidian-icon-folder` | Folder/note icons for faster visual navigation |
| **Homepage** | `homepage` | Open `Home` automatically on startup |
| **Advanced Tables** | `table-editor-obsidian` | Auto-format the staging/grading tables |
| **Kanban** | `obsidian-kanban` | Board view for exam-prep or audit projects |

> Community plugins are third-party code you install yourself from Obsidian's trusted browser —
> they can't ship inside this vault. The IDs above are exact so you can find each one instantly.

## Sync & backup (pick one)
- **Obsidian Sync** (paid) — encrypted, best on mobile; recommended for medical notes.
- **iCloud / OneDrive** — free.
- **Git** (`obsidian-git`) — auto-commit to a **private** repo only. Never a public one.

## Settings already applied
New notes → `00 Inbox` · attachments → `99 Attachments` · wikilinks on · auto-update links on ·
readable line length on · inline title on · frontmatter hidden in editor (use the Properties view).
