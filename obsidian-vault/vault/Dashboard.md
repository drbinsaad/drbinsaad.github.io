# 📊 Dashboard

Live progress across the whole ENT curriculum. Powered by the **Bases** core plugin
(Settings → Core plugins → enable **Bases**). If the board below is blank, enable Bases.

![[ENT Progress.base]]

---

## How the status lifecycle works
| Status | Meaning |
|---|---|
| `untouched` | Curriculum stub — not studied yet |
| `learning` | Started; notes in progress |
| `solid` | Understood well; could answer an exam question |
| `mastered` | Could teach it / operate on it confidently |

Change the `status` property at the top of any topic note and it moves here automatically.

## Views in the board
- **By Section** — every topic grouped by section with its status.
- **Needs work** — everything not yet `mastered` (your study queue).
- **Has sources** — topics you've already backed with a video/lecture/paper.
