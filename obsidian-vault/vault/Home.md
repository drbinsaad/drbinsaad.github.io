# 🏠 ENT Vault

Your whole ENT curriculum as notes — 8 sections, 123 topics. This is the only landing page.

## The loop (under 3 minutes)
Learn something → `Ctrl/Cmd+O` to the topic note → dump takeaways under **Notes** → paste the
source link → bump `status` (`untouched → learning → solid → mastered`). The board below updates
itself.

No time to file it? Drop a line in `00 Inbox` and process it weekly.

## Progress
> Enable the **Bases** core plugin (Settings → Core plugins) if the board is blank.
> Views: **By Section** (everything) · **Needs work** (your study queue) · **Has sources**.
