# 🏠 ENT Vault

Your ENT knowledge, exams, teaching and projects — one place. Start here.

## The loop (under 3 minutes)
Learn something → `Ctrl/Cmd+O` to the topic note → write takeaways under **Notes** → paste the
source link → bump `status` (`untouched → learning → solid → mastered`). The board updates itself.

No time to file it? Drop a line in `00 Inbox` and process it weekly.

## 📊 Curriculum progress
> Enable the **Bases** core plugin if a board is blank. Views: **By Section** · **Needs work**
> (study queue) · **High-yield** (exam-critical) · **Has sources**.
